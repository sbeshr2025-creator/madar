# مدار — منصة تداول تجريبية

موقع ومنصة تعليمية عربية (RTL) للتدرّب على تداول الأصول الرقمية **بأموال افتراضية فقط**.

- الموقع: https://sbeshr2025-creator.github.io/madar/
- المنصة: https://sbeshr2025-creator.github.io/madar/app/

## المزايا
- لوحة تحكم، أسواق، تداول فوري (سوق + محدد يُنفَّذ عند لمس السعر)، محاكي عقود آجلة حتى 20× مع وقف خسارة/جني ربح/تصفية، محفظة افتراضية، أوامر، سجل نشاط، تنبيهات أسعار، إعدادات.
- أسعار وشموع ودفتر أوامر **مرجعية للقراءة فقط** من واجهة Gate العامة (WebSocket + REST، بلا مفاتيح)، مع تحويل تلقائي إلى المحاكاة عند الانقطاع.
- مخطط شموع خفيف على Canvas بدون مكتبات خارجية.
- حفظ الحالة في `localStorage` مع إعادة ضبط، مظهر داكن/فاتح، تنقّل سفلي على الجوال، دعم لوحة المفاتيح وقارئات الشاشة.
- PWA: manifest وأيقونات وService Worker للعمل دون اتصال.

## تنبيه
لا حسابات، لا إيداع أو سحب، لا تداول حقيقي، ولا نصائح مالية. كل البيانات في متصفح المستخدم.

## البنية
```
index.html            صفحة الهبوط
css/ js/              ملفات صفحة الهبوط
app/index.html        المنصة التجريبية
app/css/app.css
app/js/charts.js      مخطط الشموع
app/js/market.js      بيانات السوق (قراءة فقط) + المحاكاة
app/js/app.js         منطق المنصة
assets/               الشعار والأيقونات وصورة المشاركة واللقطات
sw.js manifest.webmanifest 404.html robots.txt sitemap.xml
```
التشغيل محليًا: `python3 -m http.server` ثم افتح `http://localhost:8000/`.
